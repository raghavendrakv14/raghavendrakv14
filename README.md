## PM Philosophy

- **Revenue outcomes over feature counts** — a feature that doesn't move a metric isn't a feature, it's scope creep
- **Sales reps are the hardest users to win** — if the tool doesn't save them time in the first session, it's dead
- **Great GTM products live at the intersection of data quality, rep workflow, and manager visibility** — miss any one and adoption collapses
- **v1 discipline: cut everything that isn't the core signal** — you can always add; you can never un-ship complexity
- **AI in sales must earn trust before it earns adoption** — one wrong recommendation costs more credibility than ten correct ones build
